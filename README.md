# The Best Meal You Ever Had

A [make.fun](https://make.fun/bounty/u-pangg7-the-best-meal-you-ever-had-a3ac0f85) bounty entry: one sentence about the best meal I ever had.

## The entry

> The best meal I ever had was my grandmother's rendang at midnight, the beef falling apart in coconut gravy while rain drummed on the tin roof and nobody spoke, we just ate.

One dish, one night, one sound — the rain on the tin roof — and a table too busy eating to say anything at all.

## How it works

`main.ts` validates the sentence is 1-200 characters, then writes it to `/output/entry.txt`.

## Run it

```sh
node main.ts
cat /output/entry.txt
```
